# Raja Mitra Bercahaya

Situs profil dan direktori kuliner RMB, dibuat dengan Next.js App Router, React, dan TypeScript.

## Menjalankan secara lokal

```bash
npm install
npm run dev
```

Buka `http://localhost:3000`.

## Konten

- Data menu dan tiga usaha berada di `app/page.tsx`.
- Carousel menu horizontal dengan tombol panah dan titik navigasi berada di `app/menu-rail.tsx`.
- Foto sajian memakai aset GoFood; tautan sumber tersedia di halaman.
- Peta menandai alamat kantor/gudang RMB di Babakan, Bajing Kulon.
- Logo merek dan foto lokal berada di `public/brand` dan `public/products`.
